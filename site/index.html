Install

Never log in to VIT Wi-Fi again.

wificonnector spots the VIT Vellore hostel login page the moment your Mac joins the network and signs you in with your saved details. It sits in your menu bar and keeps you online.

    Your password stays in your Keychain

    macOS's own password store holds your Wi-Fi password, locked with your Mac login. wificonnector reads it only at the moment it signs you in.

    • Never written to a file or to the log.
    • Never on a command line, where other apps could see it.
    • Only sent once the VIT login page has been recognised.

    Set it up

    One command in Terminal is the easiest way, and the one we recommend. You can also download the app yourself, or run only the script. Tick each step as you finish it.

      0 of 3 done

      It only talks to the VIT login page

      You don't create an account, and nothing is sent anywhere else. What it knows stays on your Mac.

      • Your details live in your login Keychain and one small settings file.
      • Its log stays in ~/Library/Logs and never leaves your Mac.
      • The code is open, so anyone can check exactly what it does.
      • This website counts visits with GoatCounter, which uses no cookies and stores nothing about you. The app itself sends nothing anywhere.

      Questions

      Something else? Open an issue on GitHub.

      Is this an official VIT app?

      No. It's an independent, open-source project. It does what you'd do in the browser: fill in the hostel login page for you.

      Is it safe to paste a command into Terminal?

      It's a fair question to ask of any command. This one downloads the latest release from GitHub, copies the app into Applications and opens it. It never asks for your Mac password and changes nothing outside the app. You can read the installer before you run it, and the rest of the code is on GitHub.

      Does it work in the academic blocks?

      Not yet. The academic blocks use a different login page. Support for it is planned.

      Do I need Xcode?

      No. The one-line command, or the .dmg from the latest release, gives you the finished app. Xcode is only for building it yourself.

      Why does macOS say it can't verify the app?

      Apple only vouches for apps signed with a paid Developer ID, and this free app isn't. macOS warns about apps your browser downloaded; install with the Terminal command and you never see it. Already downloaded the .dmg? Click Done, not Move to Trash. Then open System Settings, go to Privacy & Security and click Open Anyway once. The code is public, so you can check what it does first.

      I can't find the icon. Where is it?

      At the top right of the screen, in the menu bar, next to the clock and the battery. On a MacBook with a notch, icons that don't fit are hidden behind it: quit an app with a menu-bar icon and it shows up. It's working either way, and you can reopen the welcome window from its menu with Set Up….

      What happens if my password is wrong?

      The portal says so, wificonnector shows a notification, and it waits five minutes before trying again so your account doesn't get locked. Fix it with wificonnector setup or the app's Settings.

      I use Cloudflare 1.1.1.1 or a VPN. Will it work?

      Yes. Before you're logged in, it looks names up through the network's own DNS and, if needed, talks to the router directly. It has been tested with Cloudflare's app switched on.

      How does it know it's on VIT Wi-Fi?

      It only sends your details when the network redirects to the VIT hostel login page, and, when macOS shows the network name, only if that name contains "VIT".

      How do I remove it?

      Run wificonnector uninstall. Add --purge to delete your saved details as well.
